Тоша — растровые персонажи (первый комплект)

Файлы hamster.png, cat.png, bunny.png, deer.png, dragon.png, fox.png, bear.png — отдельные PNG 512x512 с прозрачным фоном.

Для добавления в репозиторий скопируйте все семь файлов в:
assets/pets/

Не переименовывайте файлы: идентификаторы должны совпадать с именами видов в pets.js.

Это цельные иллюстрации персонажей в idle-позе. Для полноценной анимации отдельных частей (лап, ушей, хвостов, глаз) понадобятся отдельные слои/варианты поз; текущий набор можно использовать как основной растровый слой и для карточек выбора питомца.
