# Тоша — тихий помощник

Бесплатное приложение для себя: питомец Тоша мягко напоминает записать еду, предлагает лёгкие мини-задания на движение, считает воду, XP, уровни, серии дней и значки. Никаких аккаунтов и серверов: все данные хранятся только на вашем телефоне.

## Как запустить бесплатно (один раз, ~5 минут)

Приложению нужен https-адрес, чтобы работали установка и уведомления. Самый простой бесплатный вариант:

**GitHub Pages**
1. Создайте бесплатный аккаунт на github.com и новый репозиторий (например, `tosha`), публичный.
2. Загрузите в него все файлы из архива (Add file → Upload files), сохраните. Папок внутри нет: все файлы лежат на одном уровне, их можно выбрать и загрузить прямо с телефона. Важно загрузить и картинки (`icon-*.png`, `shot-*.png`, `apple-touch-icon.png`), иначе PWABuilder покажет ошибки про иконки.
3. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
4. Через минуту-две приложение будет по адресу `https://ВАШ_ЛОГИН.github.io/tosha/`.

Проверка: откройте `https://…/icon-512.png`, должна показаться иконка.

Альтернативы: Netlify Drop (перетащить папку на страницу app.netlify.com/drop) или Cloudflare Pages. Оба бесплатны.

## Установка на Android
1. Откройте адрес в Chrome.
2. Меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).
3. Откройте Тошу с экрана и нажмите «Разрешить» в карточке про уведомления.

## Как работают напоминания
- Только тихие: без звука и вибрации (можно включить в «Ещё»), не в тихие часы (по умолчанию 22:00–08:00).
- Еда: один раз в течение 90 минут после выбранного времени, если запись ещё не сделана.
- Движение: мини-задание не чаще чем раз в 2 часа и не больше 3 в день (настраивается).
- Итог дня: один раз вечером.
- Пока приложение открыто, подсказки появляются баннером внутри него.
- Честное ограничение: приложение без своего сервера не может гарантированно будить телефон в точное время. Chrome на Android иногда проверяет напоминания в фоне, но редко и не по расписанию. Поэтому лучшая привычка: заглядывать к Тоше утром.

## Темы и достижения
- «Ещё» → «Оформление»: режим (авто / светлая / тёмная) и палитра (персик, мята, лаванда, океан).
- «Ещё» → «Достижения»: 37 значков по группам (еда, движение, вода, серии, уровни, питомцы) с прогрессом. Награды выдаются по факту, наказаний за пропуски нет.

## Сделать APK (PWABuilder)
1. Откройте pwabuilder.com, вставьте адрес приложения, «Start».
2. Когда манифест без ошибок, нажмите «Package for stores» → Android.
3. Скачайте пакет и сохраните ключ подписи (он нужен для обновлений).
4. Если адрес вида `логин.github.io/tosha/`, файл `assetlinks.json` в корень не положить, и в приложении может остаться адресная строка. На Netlify/Cloudflare Pages с собственным адресом этого нет.
5. Фоновые уведомления в APK не гарантированы, как и в браузере.

## Питомцы и анимации
Шесть питомцев на выбор: хомяк, кот, кролик, дракончик, лисёнок, медвежонок. Все нарисованы кодом (`pets.js`) из отдельных частей: корпус, голова, уши, лапы, хвост, крылья.

Анимации тоже считаются кодом (`anim.js`), готовых файлов нет. В библиотеке 29 анимаций (включая эволюцию: вылупление на 2 уровне, эволюция на 3 и 5, коронация на 8): покой, радость, восторг, грусть, сон, пробуждение, ходьба, бег, прыжки, приседания, растяжка, танец, голод, еда, жажда, питьё, усталость, «выдохся», расслабление, настрой, приветствие, тренировка завершена, цель достигнута, награда, новый уровень, выпил воды.

Питомец реагирует на действия: записал еду, выпил воды, выполнил задание, новый уровень, возвращение в приложение. Тап по питомцу запускает случайную весёлую реакцию. Спящий и голодный питомец сам показывает свою анимацию.

## Мастерская (вкладка 🎨)
Правки без кода, прямо на телефоне:
- просмотр всех анимаций с ползунком скорости и повтором по кругу;
- свои цвета питомцев;
- свои мини-задания (значок, текст, время, награда);
- свои фразы питомца.
Всё хранится на телефоне и входит в «Сохранить копию».

## Свои задания и тексты
- Список мини-заданий: `core.js`, массив `QUESTS` (добавляйте свои строки).
- Встроенные фразы питомца: `app.js`, объект `PHRASES` (свои проще добавить в Мастерской).
- Поменяли файлы? В `sw.js` увеличьте номер в `CACHE = 'tosha-v6'`, иначе телефон покажет старую версию.

## Данные
«Ещё» → «Сохранить копию» скачивает файл со всеми записями, «Загрузить копию» возвращает их (например, на новом телефоне).

Приложение не является медицинским и не даёт рекомендаций по питанию. Цель по калориям лучше обсуждать с врачом или диетологом.

## Настоящее Android-приложение (без адресной строки)
Файлы `package.json`, `capacitor.config.json`, `tosha-debug.keystore` и `build-apk.yml` нужны только для сборки APK на GitHub. Если вы их не загрузите, сайт-версия работает как раньше.
Как собрать: положите `build-apk.yml` в репозиторий как `.github/workflows/build-apk.yml`, загрузите остальные файлы, откройте вкладку Actions → «Собрать APK» → Run workflow. Готовый `tosha.apk` появится в Releases.
В такой сборке уведомления планируются в самом телефоне на 3 дня вперёд и обновляются при каждом открытии приложения.

## Справочник продуктов
Список зашит в начало файла `app.js` (блок «Справочник продуктов») и хранит около 430 продуктов и блюд (ккал на 100 г или 100 мл, обычная порция). На вкладке «Еда» начните вводить название: появится список, после выбора подставятся граммы и калории, граммы можно менять. Значения примерные. Свои продукты добавляйте в этот блок по одной строке: `эмодзи|название|ккал на 100|порция в граммах|как называется порция`.
